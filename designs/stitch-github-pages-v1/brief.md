# AI Workflow Vault GitHub Pages Redesign Brief

Product: AI Workflow Vault, a public GitHub Pages site that showcases reusable AI production workflows.
Audience: global creators, non-dev founders, AI-curious professionals, and developers who want practical workflows.
Primary goal: make the site feel like a premium AI production studio and workflow library, not a plain repo index.
Core action: open the YouTube Shorts AI Learning workflow and understand the production loop quickly.
Screens: public homepage plus workflow detail page.
Tone: premium, clear, cinematic, trustworthy, tool-native.
Constraints: static GitHub Pages, plain HTML/CSS, accessible contrast, responsive desktop/mobile, no fake metrics, no unreadable tiny text.
Content to preserve: AI Workflow Vault, YouTube Shorts AI Learning Video, Design Workflow Studio, research/script/voice/render/QA/upload loop, Supertonic local narration.
Requested Stitch direction: create a full UI/UX design for the GitHub Pages site with strong information architecture, hero, workflow cards, production pipeline, quality gates, and design-system polish.
